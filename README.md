# **Reinforcement Learning Assignments**  
This repository contains three homework assignments focused on reinforcement learning techniques. Each assignment explores different aspects of RL, from basic learning algorithms to advanced deep Q-networks.  

## ***Assignment 1: Traditional RL Agents***  
This assignment focuses on implementing the following agents:  

- TD Learning  
- SARSA  
- Sarsa(λ)  
- Q-learning  
- General Q-learning  

## ***Assignment 2: Exploration vs. Exploitation and Model-based RL***  
This assignment explores various exploration vs. exploitation strategies and a model-based RL approach:  

- **Exploration Strategies:**  

  - Greedy  
  - ε-greedy  
  - Upper Confidence Bound (UCB)  
  - REINFORCE  

- **Model-based RL:**  

  - Dyna-Q – Combines model learning with Q-learning for enhanced performance.  

## ***Assignment 3: Deep Q-Network (DQN) Agent***  
This assignment involves implementing a DQN agent that includes:  

- A neural network that predicts Q-values for a given observation.  
- An experience replay buffer to store transitions.  
- A target Q-network for stabilizing the learning process.
